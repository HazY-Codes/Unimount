Orchestrator Policy (/data/adb/unimount/config.conf)

Changes write immediately to disk and apply on next mount run or soft reboot.

Manual Whitelist Mode (MOUNT_MODE=manual)
Only mount modules explicitly listed in /data/adb/unimount/modules.txt. When off, Auto Mode mounts all overlay modules except those with skip_unimount.
SELinux Context Mirroring (SELINUX_MIRROR=1)
Clones target file SELinux label (u:object_r:*) and POSIX permissions before bind-mounting. Fail-closed under Enforcing to prevent avc denials.
Directory Mirror Injection (DIR_MIRROR_INJECT=1)
Composes minimal-ancestor directory mirrors in /data/adb/unimount/mirror to inject new files, folders, and symlinks without OverlayFS or tmpfs.
Skip Zygisk / Service-Only Modules (SKIP_ZYGISK_ONLY=1)
Bypass overlay processing for modules without partition folders (system, vendor, product, system_ext, odm, prism, optics).
Bootloop Circuit Breaker (BOOTLOOP_GUARD=1)
Automatically skips all overlays after 2 consecutive incomplete early boots/mount runs; resets via boot-completed.sh, 25s post-mount health check, or WebUI.
Protect Critical System Paths (PROTECT_CRITICAL_PATHS=1)
Blocks bind-mounts and directory mirrors over panic-critical binaries (init, linker*, vold, *servicemanager) and SELinux policy directories.
Verbose Mount Telemetry (LOG_VERBOSE=1)
Log every individual file bind-mount, mirror stage, duplicate skip, and module skip to /data/adb/unimount/mount.log.
